## 2. 怎么玩（最短路径）

1. 双击 `开始游戏.bat` 或 `Builds\SwanV01.exe`。
2. 看完 7 步教程（或按 Esc 跳过）。
3. WASD 走，鼠标点蓝框里的格子。
4. 按 1 种植，按 ] 调到 ×60，等成熟，按 2 收获。
5. 按 O 改设置，按 Tab 看背包，按 F1 重看教程。

完整键位见 `README.md` §1。

## 4. 修了哪些旧问题

1. **植物长大不重绘**：`World.UpdateDirtyFromSwap` 原来只比较地形/植物类型/成熟标记，
   漏了 `Growth`；现在比较 `Growth`、`StructureId`、`ForageItemId`。
2. **显式尺寸世界没有野物**：`SeedForage()` 原来只在 preset 分支调用，导致测试世界 `ForageCount=0`；
   现在构造末尾统一调用，并对最小 DataBundle 做 null guard。
3. **收获物品名对不上主键**：植物表 `yieldItem=食物纤维` 是显示名，物品表主键是 `produce_p01`；
   新增 `ItemTable.TryResolve`，先按 id 再按 name。
4. **打包程序每帧异常**：`DebugHud` 读旧的 `UnityEngine.Input.mousePosition`，工程启用 Input System 后每帧抛
   `InvalidOperationException`；改用 `Mouse.current.position.ReadValue()`。
5. **范围层盖住植物**：层级从 Ground/Decor/Zone/Heat/Cursor 改为
   Ground/Zone/Decor/Heat/Cursor。
6. **范围边框过粗**：Zone 改为按像素分辨率绘制，边框 2px。
7. **玩家过大/过小**：`playerSpriteScale` 默认 1.25，可在设置里实时调。
8. **教程每次都弹**：用 `PlayerPrefs("swan.tutorialSeen")` 记住；F1 可重开。

## 5. 设计取舍 / 已知边界

- **脑图读不到**：`zhixi.com` 需要微信扫码登录，headless/无登录 Edge 只能拿到登录弹窗；
  Edge 正在运行且 Cookies 被锁，无法复制会话。实现以交接包 `docs/handoff-v2.md`、
  `design/gdd/`、数值表 CSV 和需求里点名的“挖掘/放置/收集”为准。
- **只开放 P01**：数值表里另外 5 种植物 `v01Active=0`。开放方法是把该列改 1 并加种子物品，
  见 `Docs/改数值与美术.md` §6。
- **树/灌木/浆果丛仍是景物**：不挡路、不挡种植、不可砍伐；**岩石已经是结构**，会挡路，
  按 5 采集可搬走换石头（见 `Docs/改数值与美术.md` §3）。
- **没有存档**：退出重开按 `mapSeed` 生成同一张地图，但玩家进度/背包不保存。
- **没有音效**：美术包里的音效未接入。
- **设置面板不是所有项都“即时”**：拖动 −/+ 只改内存，点“保存并立即应用”才写文件并重载；
  重载会保留世界状态（植物按 typeId 重映射）。
- **景物/野物在重建地图时重新生成**：按 `mapSeed` + 稳定哈希，同一配置下一致。
