# 改数值与美术（不用写代码）

> 原则：**所有可调数值都在 `Assets/StreamingAssets/Data/`，所有图都在 `Assets/StreamingAssets/Art/`。**
> 代码只读这些文件，所以改完不用碰 C#。

---

## 0. 先搞清楚「改哪一份」

| 你在哪运行 | 数据在哪 | 美术在哪 |
|---|---|---|
| Unity 编辑器 Play | `Assets/StreamingAssets/Data/` | `Assets/StreamingAssets/Art/` |
| 打包后的 exe | `Builds/SwanV01_Data/StreamingAssets/Data/` | `Builds/SwanV01_Data/StreamingAssets/Art/` |

编辑器里改完 → 游戏里按 **F5** 热重载（保留世界），或 **R** 重建地图。
打包版改完 → 游戏里按 **F5**；但改 `art.json`/换 PNG 需要**重新打包**，因为打包时
StreamingAssets 是复制进去的。赶时间也可以直接改 `Builds/SwanV01_Data/StreamingAssets/` 下的副本。

## 1. `config.json`：最常改的数值

字段按功能分组（设置面板里的项就是这些键）：

| 键 | 默认 | 含义 |
|---|---|---|
| `tickRate` | 4 | 视觉刷新/秒 |
| `envStepSeconds` | 20 | 一个环境步多少秒 |
| `maxEnvStepsPerFrame` | 8 | 一帧最多补几个环境步 |
| `gridWidth` / `gridHeight` | 50 / 50 | 地图尺寸 |
| `cellPixelSize` | 16 | 一格多少像素（美术包是 16） |
| `speedLevels` | [1,10,60] | `[` `]` 切换的倍速 |
| `defaultSpeed` | 1 | 开局倍速 |
| `growthSpeedMultiplier` | 1.0 | 生长速度倍率（也会影响所有植物） |
| `playerMoveCellsPerSecond` | 5 | 主角移动速度（格/秒） |
| `playerSpriteScale` | 1.25 | 主角渲染大小 |
| `playerAnimationFps` | 9 | 行走动画帧率 |
| `playerCollisionRadius` | 0.32 | 碰撞半径（格） |
| `playerStartX` / `playerStartY` | 18 / 38 | 出生格；-1 = 自动找地图中心附近 |
| `interactionWidth` / `interactionHeight` | 12 / 12 | 交互范围（格） |
| `walkableMaxWater` | 55 | 水深超过多少不能走 |
| `digMaxWater` | 75 | 水太深不能挖 |
| `seedReturnOnHarvest` | 1 | 收获返还几颗种子 |
| `forageRegrowChance` | 0.0015 | 每个环境步野物再生概率 |
| `forageMaxCount` | 140 | 野物数量上限 |
| `rockChance` | 0.018 | 每个可站格铺岩石的概率；0 = 不铺 |
| `rockStructureId` | 5 | 岩石用结构表里的哪一行（5 = 岩石） |
| `rockSeed` | 20261119 | 岩石落点随机种子；改数字就换一批落点 |
| `envStepsPerDay` | 24 | 一天几个环境步（只影响 HUD 天数） |
| `toastSeconds` | 3.2 | 底部提示停留秒数 |
| `zoneColor` / `zoneOutOfRangeColor` | #5CC8FF / #FF7A6B | 范围内/外光标颜色 |
| `zoneFillAlpha` / `zoneBorderAlpha` | 0.04 / 0.8 | 范围填充/边框透明度 |
| `hudFontSize` / `hudMargin` / `hudPanelAlpha` | 13 / 10 / 0.94 | HUD 字号/边距/面板不透明度 |
| `uiPanelColor` / `uiButtonColor` / `uiTextColor` … | 见文件 | 面板、按钮、文字、强调色 |

> **注意**：`config.json` 和 `config.default.json` 是两份。前者是当前值，后者是「恢复默认」读的值。
> 想让默认值也变，两份都改。

验证：改坏了会启动报错，错误信息会带「文件名 + 行号 + 列名」，例如
`config.json · 列 cellPixelSize: 必须 ≥ 1`。

## 2. 物品表：加一种种子 / 一种放置物

文件：`数值表(物品表)-机读.csv`

列：

```
itemId,name,category,iconFile,srcX,srcY,srcW,srcH,stackMax,placeStructureId,seedPlantId,startingCount,description
```

- `category`：`seed` / `produce` / `material` / `placeable` / `tool`（HUD 只按这几个分类显示）
- `seed` 必须填 `seedPlantId`（对应植物表 `typeId`）
- `placeable` 必须填 `placeStructureId`（对应结构表 `structureId`）
- `startingCount` > 0 的会在新游戏里直接进背包
- `iconFile` 是 `Art/` 下的文件名，`srcX/srcY` 是 PNG 左上角起算的像素坐标

**例：加「灌木种子」**

```csv
seed_p02,灌木种子,seed,Basic_Plants.png,0,16,16,16,99,0,P02,4,种下会长成灌木
```

再把植物表 P02 的 `v01Active` 改成 `1`，按 F5。
（灌木的 `yieldItem` 写的是「野果种子」，物品表里要有一行 `name` 叫「野果种子」的物品，
或者把它改成某个已存在的 `itemId`。）

## 3. 结构表：栅栏 / 箱子 / 营火 / 木地板 / 岩石

文件：`数值表(结构表)-机读.csv`

列：

```
structureId,name,blocksMovement,blocksPlanting,spriteFile,srcX,srcY,srcW,srcH,tint,itemId,description
```

- `blocksMovement=1`：挡路
- `blocksPlanting=1`：不能在这格种植
- `itemId`：采集（动作 5）收回时给哪个物品
- `tint`：`#RRGGBB` 染色

加一个新结构：加一行，再在物品表加一个 `category=placeable`、`placeStructureId` 指向它的物品。

**岩石（结构 5）**：`blocksMovement=1`、`blocksPlanting=1`，图块用 `Basic_Grass_Biom_things.png` 的 `(80,64)`，`itemId=stone`。
它由 `config.json` 的 `rockChance/rockStructureId/rockSeed` 自动铺在地表；按 **5 采集** 可以搬走并换回 1 个石头。
想关掉岩石：把 `rockChance` 改成 `0`，按 **R** 重建地图。

## 4. 动作表：改消耗/效果

文件：`数值表(动作表)-机读.csv`

列：

```
actionId,name,hotkey,selectsCategory,costItem,gainItem,power,power2,power3,description
```

- `hotkey`：1–8，对应游戏里的数字键
- `selectsCategory`：`seed` / `placeable` / 空
- `costItem`：执行一次消耗什么（空 = 不消耗）
- `gainItem`：执行一次获得什么（空 = 不获得）
- `power`：主效果值。当前约定：
  - 挖：`power` = 扣水，`power2` = 扣养分，`power3` = 获得几个 `gainItem`
  - 浇水：`power` = 加多少水
  - 施肥：`power` = 加多少养分

**例：把浇水从 +12 改成 +20**

```csv
water,浇水,6,,,water,20,0,0,浇一桶水
```

按 F5 生效。

> 动作行数不要超过 8（动作栏和数字键按 8 个设计）。要加第 9 个，需要同时改
> `DebugHud.DrawHotbar` 和 `SwanBootstrap.HandleActionKeys` 的循环上限。

## 5. 采集物表：哪个地形长什么

文件：`数值表(采集物表)-机读.csv`

```
terrainId,itemId,chance
```

- 每个地形一行；`chance` 0–1，越大越密
- `itemId` 必须在物品表里存在
- 野物会占格：有野物的格子不能种，先按 5 采集

地形 id 见 `数值表(地形属性表)-机读.csv`（1 荒漠 … 25 生命之泉）。

## 6. 植物表：开放另外 5 种

文件：`数值表(植物类型表)-机读.csv`

把对应行的 `v01Active` 从 `0` 改成 `1`，再给玩家一个能种它的种子物品（见第 2 节）。

注意：

- `growthPerStep` 是每个环境步长多少（100/`growthSteps` 附近）
- `requiredWaterMin/Max`、`requiredNutrientMin` 是生长门槛
- `baseYield` 是收获数量；`yieldItem` 可以写物品 `itemId` 或物品显示名
- `passable=0` 的植物会挡路（目前 P01 是可穿过的）
- 改了曲线相关的列，原 v0.1 的 B1/B2 对照测试可能会失败——这是预期的，需要同步更新测试或
  只改 `v01Active`。

## 8. 美术：`art.json`

文件：`Assets/StreamingAssets/Art/art.json`

### 8.1 地面

```json
"ground": [
  {"terrainId":7,"file":"Tilled_Dirt_v2.png","x":0,"y":80,"tint":"#FFFFFF"},
  ...
]
```

- `terrainId` 对应地形表
- `x,y` 是 **PNG 左上角**起算的像素坐标
- `tint` 乘在像素颜色上，`#FFFFFF` = 原色；想把草地染黄就写 `#D8C878`
- 同一个 `file` 只加载一次，换图只要换文件名

地面无缝图块：`Grass.png` / `Tilled_Dirt_v2.png` 的 `(0,80)`、`(16,80)` 一带；
`Water.png` 的 4 帧在 `(0,0)..(48,0)`。

### 8.2 植物

```json
"plants": [
  {"typeId":"P01","file":"Basic_Plants.png","row":0,"tint":"#FFFFFF","stages":[1,2,3,4]}
]
```

`row=0` 黄绿作物，`row=1` 紫色作物；`stages` 是 4 个生长阶段对应的列号（0 是种子袋，5 是物品）。

### 8.3 地面散景（小花/落叶/石头）

```json
"scatter": [
  {"file":"Basic_Grass_Biom_things.png","x":96,"y":16,"chance":0.025,"terrains":[3,4,7,8]}
]
```

`chance` 是每格出现概率；`terrains` 是允许的地形 id 列表。同格每次结果固定，不会闪。

### 8.4 大树/灌木/浆果丛（景物）

```json
"props": [
  {"file":"Basic_Grass_Biom_things.png","x":0,"y":0,"w":48,"h":48,
   "chance":0.025,"terrains":[4,8,9,14,15],"offsetY":-1.1}
]
```

`props` 用独立 Sprite 画，可以跨多格（树是 48×48 = 3×3 格）。
**树木/灌木/浆果丛目前只是景物，不挡路、不挡种。**
挡路的岩石走的是结构表（见 §3），不是 `props`；所以不要再往 `props` 加石头，否则会出现“看得见却穿得过”的假石头。

### 8.5 角色

```json
"player": {
  "sheet":"Basic Charakter Spritesheet.png",
  "cell":48, "spriteX":16, "spriteY":16,
  "spriteW":16, "spriteH":16, "frames":4, "directions":4
}
```

角色 sheet 是 4×4 个 48×48 大格，每格左上角 16×16 是猫；行=朝向（下/上/左/右），列=行走帧。
要换角色，把新 sheet 放到 `Art/`，改这里即可。

### 8.6 物品/动作图标

物品图标在物品表的 `iconFile/srcX/srcY/srcW/srcH`；
动作图标在 `art.json` 的 `"actions"` 数组。

## 9. 加一张新图

1. 把 PNG 复制到 `Assets/StreamingAssets/Art/`。
2. 在 `art.json` 里引用文件名（区分大小写）。
3. 编辑器里 Play 即可看到；打包版要重新打包，或把 PNG 也复制到
   `Builds/SwanV01_Data/StreamingAssets/Art/`。

PNG 不经过 Unity 的 Sprite 导入，运行时用 `Texture2D.LoadImage` 读，所以：
**像素风请保持原始尺寸，不要放大后再存**；代码用 `Point` 采样。

---

## 10. 改完怎么验证

1. 游戏里按 **F5**：热重载 `config` + 所有 CSV + `map-preset`，保留世界。
2. 按 **R**：按 `map-preset.json` 重建地图（会重新铺野物/景物）。
3. 改 `art.json`/PNG：编辑器 Play，或重新打包。
4. 跑测试：

```
Unity.exe -batchmode -nographics -projectPath <工程> ^
  -runTests -testPlatform EditMode -testResults Docs\tests8.xml -logFile Logs\tests.log
```

改数值导致的曲线测试失败不一定是 bug，先看 `Docs/DECISIONS.md` 里 B1/B2 的裁定。
