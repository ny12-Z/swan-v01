# SWAN · v0.1 —— 2D 像素农场原型（Unity 6）

一个用 **Unity 6000.6.6f1** 做的 2D 像素农场实验：猫耳角色在一块会自己演化的土地上走动、开垦、浇水、播种、收割。

土地不是「一块块写死的瓦片」，而是**带属性的单元格**：每格有 `水分 / 养分 / 植被` 三个数值，类型由数值**算出来**，贴图跟着类型换。所以浇水会把旱地泡成普通土地，斧头砍掉植被会把草原变成土地，水分蒸发够久了又会退回旱地 —— 这些都不需要写规则脚本，全部由「数值 + 阈值」驱动。

- 引擎：**Unity 6000.6.6f1**（项目版本文件已对齐）
- 输入：只启用新 **Input System**（`activeInputHandler = 1`）
- 渲染：2D URP 无关，纯 SpriteRenderer + Tilemap；像素完美（PPU 16、Point 过滤）
- 场景入口：`Assets/Scenes/SampleScene.unity`

## 1. 快速开始

1. Unity Hub 用 **6000.6.6f1** 打开本仓库根目录（工程根就是仓库根，`Assets/`、`Packages/`、`ProjectSettings/` 都在这一层）。

## 2. 玩家操作

| 按键 | 作用 |
|---|---|
| **W A S D** / **方向键** | 四方向移动（斜向不会加速） |
| **F** | 进入 / 退出「互动模式」（拿起工具，此时仍可正常走动） |
| **鼠标滚轮** | 互动模式下切换道具：锄头 → 斧头 → 水壶 → 播种 → 循环 |
| **1 / 2** | 选中「播种」后切换种子：`1` 小麦、`2` 苹果 |
| **鼠标左键** | 对鼠标所指的格子使用当前道具（播种模式下也用于**收获**） |
| **F1** | 调试面板显示 / 隐藏（仅编辑器） |

### 一次完整的农活流程

1. 走到草地上，按 **F**，滚轮切到 **锄头**，把鼠标移到脚边的草地 → 出现**黄色方框**（表示够得着、可交互）。
2. 左键 → 角色播一遍锄地动作，那格草被翻成**旱地**（Tilled 贴图）。
3. 切 **水壶**，左键浇水 → 旱地水量上涨，变成**普通土地**（这一格现在能种了）。
4. 切 **播种**，按 `1` 选小麦，左键 → 种下一株小麦。
5. 等 **4 分钟**（同一格可以连续浇水慢慢养），小麦走完 4 个成长阶段后成熟。
6. 播种模式下再左键那株小麦 → 收获（当前只打日志，背包系统待做）。

光标框的颜色就是规则提示：

- 🟨 **黄色** = 这一格能交互
- 🟥 **红色** = 超出身边 4×4、或被碰撞挡住够不着、或水面等不可作用的目标

## 3. 机制说明

### 3.1 时间刻（tick）系统

游戏里有一个全局时钟 `时间tick`，默认 **每秒 4 刻**（`每秒刻数 = 4`，可在 `时间系统` 的 Inspector 里改，改成 40 就是 10 倍速快进）。

每过一刻会广播事件，环境演化按「间隔刻数」取模后结算：

| 规则（`环境规则.asset`） | 默认值 | 含义 |
|---|---|---|
| 衰减间隔刻 | 4 | 每 4 刻（= 1 秒）结算一次衰减 |
| 每间隔水分变化 | -0.1 | 每格每秒少 0.1 水分 |
| 每间隔养分变化 | -0.1 | 每格每秒少 0.1 养分 |
| 水影响半径 | 3 | 切比雪夫方形半径 3 格 |
| 水影响间隔刻 | 4 | 每 4 刻结算一次补水 |
| 水影响水分 | +0.2 | 半径内有纯水就补水 |

所以：**一格里水只有 0.1/秒地慢慢蒸发**，靠水源（湖）附近的格子会被持续回补，远离水的旱地会越来越干。—— 这一层就是后面接「天气 / 季节 / 昼夜」的挂点，现在只留了「每刻数值变化」三个字段在 `单元格类型.asset` 里作为占位。

> `时间tick.已过刻数` 是序列化字段，Play 中能在 Inspector 里实时看到跳数；C# 侧也可以 `时间tick.当前.刻数` 读。

### 3.2 单元格：三个属性，四种类型

**属性**（`单元格属性` 枚举，可扩展）：

| 属性 | 含义 |
|---|---|
| 水分 | 0–100，越高越湿 |
| 养分 | 0–100，越高越肥 |
| 植被 | 0–100，草地/树林的「绿化度」 |

数值存在 `地图数据` 的运行时字典里（`Dictionary<Vector2Int, 单元格状态>`），**不写进 Tile 资产**——因为 Tile 是共享资源，写进 Tile 会让整张地图一起变。

**类型**（`单元格类型` 枚举）与初始值：

| 类型 | 水分 | 养分 | 植被 | 瓦片来源 | 可通行 | 参与初始识别 |
|---|---|---|---|---|---|---|
| 草原 | 50 | 55 | 100 | Grass + Hills（154 张变体） | ✔ | ✔ |
| 旱地 | 28 | 30 | 0 | Tilled_Dirt 系列（308 张） | ✔ | ✔ |
| 普通土地 | 45 | 60 | 0 | 单张 `Tilled_Dirt_Wide_12` | ✔ | ✘ |
| 纯水 | 95 | 5 | 0 | Water（4 张） | ✘ | ✔ |

**类型是算出来的，不是存出来的** —— `地图规则.判定类型(水分, 养分, 植被)` 按优先级从高到低判：

1. `水分 ≥ 85 && 植被 < 20` → **纯水**
2. `植被 ≥ 40` → **草原**
3. `水分 ≥ 40 && 养分 ≥ 28` → **普通土地**
4. `水分 ≥ 24 && 养分 ≥ 36` → **普通土地**（「翻过土」的旱地，锄一下就能到）
5. 其余 → **旱地**

几个能对上的例子：

- 旱地浇水一次：`28/30/0 → 48/30/0` → 命中第 3 条 → **普通土地** ✔
- 草原砍一斧：`50/55/100 → 47/52/0` → 第 1、2 条都不成立 → 第 3 条命中 → **普通土地** ✔
- 草原浇水：`50/55/100 → 70/55/100` → 第 2 条命中 → 还是**草原**（水多但草没被清掉）✔
- 普通土地放着不种：每秒 -0.1 水，约 50 秒后水量 < 40 → 退回**旱地** ✔

> 「普通土地」为什么 `参与初始识别 = false`：它和旱地共用 Tilled 贴图，如果参与识别，开局所有锄过的 Tilled 格子都会被读成普通土地，分不出「刚翻的土」和「能种的土」。

**瓦片是怎么换的**：属性变化 → 重算类型 → 类型变了就发 `类型变化` 事件 → `单元格显示` 把该格换成新类型对应的瓦片（同类型有多张变体时按坐标散列固定挑一张，避免整片地花纹重复）。

### 3.3 交互：范围、可达、增量

**范围**：`交互范围格数 = 4`，按 `左下 = 玩家格 - (边长-1)/2` 算，也就是覆盖玩家周围 **4×4 = 16 格**（玩家左上 1 格到右下 2 格）。改成 5 就是居中 5×5。

**可达（够不够得着）**：从玩家格出发做 8 邻域 BFS，可行走的条件是

```
有格子 && 该类型可通行 && 碰撞层(Collision Tilemap) 在这一格没有瓦片
```

目标格在可达集合里、或与可达格 8 邻接，就算够得着。所以站在湖边**浇不到湖中心**（四周全是不可通行的水），但贴着岸边那一格可以。

**道具增量**（`地图规则.asset`）：

| 道具 | 水分 | 养分 | 植被 |
|---|---|---|---|
| 浇水 | +20 | 0 | 0 |
| 锄头 | -4 | +6 | -100（清零） |
| 斧头 | -3 | -3 | -100（清零） |
| 播种 | 不改属性，只种作物 | | |

对纯水格使用道具：**动作照播，属性不变**（避免把湖填成陆地）。

### 3.4 作物

- 只有 **普通土地** 且 **空格** 才能播种（`作物系统.能否播种` 会给出具体原因：没有地 / 已有作物 / 不是普通土地…）。
- 每种作物 4 张成长帧，`成熟秒数 = 240`（4 分钟）→ **每阶段 60 秒**。
- 作物是**独立的 SpriteRenderer**（不走 Tilemap），`sortingOrder = -4`，位置 = 格中心 + `(0, -0.5, 0)`（成长帧轴心在底边，从地面往上长）。
- 成熟后左键即可收获；收获目前只 `Debug.Log("[作物] 收获 …（背包系统待做）")`，**不收任何东西**——这是给背包系统留的接口（`作物系统.收获完成` 事件 + `作物定义.收获物` 贴图已切好待用）。
- 小麦 = 上排（`y=16`），苹果 = 下排（`y=0`），图标都取自 `Basic_Plants.png` 的左一列。

### 3.5 HUD

- Canvas：Screen Space - Overlay，`CanvasScaler` 1920×1080、Match 0.5。
- 左下角工具栏：**484 × 124**，四个 88×88 槽位（中心 x = 62 / 164 / 266 / 368）+ 右侧 44×44 的 `F` 键帽（x = 444）。
- 状态：未互动整体 alpha 0.7；互动中 1.0；**选中的槽位亮金色高亮 + 放大 1.1**，未选中图标 alpha 0.45。
- 第 4 槽（播种）的图标会随当前种子（小麦 / 苹果）自动切换。
- HUD 上**没有** `GraphicRaycaster` / `EventSystem` —— 它只是显示，不挡鼠标操作。

### 3.6 相机（Cinemachine）

```
相机管理
├── Main Camera        （CinemachineBrain）
└── 跟随相机            （CinemachineCamera + CinemachineFollow）
```

- 跟随偏移 `(0, 0, -10)`，位置阻尼 `(0.15, 0.15, 0)`，`绑定模式 = WorldSpace`。
- 目标是 `玩家` 的 Transform，镜头类型沿用主相机的正交（Orthographic Size 5）。
- 想加「镜头不越出地图边界」时，给跟随相机加 `CinemachineConfiner2D`，把 Collider 设成地图外框即可。

### 3.7 排序层（Sorting Order）速查

| 对象 | Order |
|---|---|
| `ground_under`（地表下层） | -10 |
| `ground-above`（地表上层，Tilled 画在这层） | -5 |
| 作物 | -4 |
| 玩家 / 互动角色 | 0 |
| 光标框 | 200 |
| HUD 画布 | 10（Canvas Sorting Order，独立于 Sprite） |

规则：**地表 → 作物 → 角色 → 光标**。加新东西时按这个顺序插值，别让作物盖住角色。

## 6. 功能实现（关键代码路径）

脚本都在 `Assets/scripts/`，按系统分目录（**中文类名 = 文件名**，Unity 才能挂得上）：

| 系统 | 脚本 | 干的事 |
|---|---|---|
| 移动 | `玩家移动.cs` | `FixedUpdate` 里读键盘 → `刚体.linearVelocity = 方向 * 速度`；维护朝向 `Dir`(0下/1上/2左/3右) 与 `Speed` 两个 Animator 参数；`可移动` 开关供互动锁定 |
| 走路动画 | `PlayerAnimSetup.cs` | 编辑器工具：生成 `Idle_*/Walk_*` 8 个 clip + `玩家动画.controller`（8 条 AnyState 过渡），把 Animator 挂到玩家 |
| 互动 | `玩家互动.cs` | F 进出互动、滚轮换道具、`1/2` 换种子、左键使用；把 `道具/方向/播放` 推给动作 Animator；用 `动作时长` 计时结束动作 |
| 动作动画 | `互动动画搭建.cs` | 编辑器工具：把 24 张动作图切成 `动作_{道具}_{方向}_{举/落}`，生成 24 个 clip + 3 个子状态机（锄头/斧头/水壶）+ 播种借用锄头 |
| 地图数据 | `地图/地图数据.cs` | `Awake` 扫 `地表层[]` 建 `Dictionary<坐标, 单元格状态>`；`加属性()` 内部 clamp → 重算类型 → 发 `类型变化` |
| 地图规则 | `地图/地图规则.cs` | 纯数据 + 两个纯函数：`判定类型()`、`取增量()` |
| 地图显示 | `地图/单元格显示.cs` | 订阅 `类型变化`，按新类型换瓦片（`SetTile`） |
| 地图交互 | `地图/地图交互.cs` | 鼠标 → 格子；`在范围()`、`可达()`（BFS）、`评估()`、`对格子使用()` |
| 光标 | `地图/单元格光标.cs` | 互动中显示鼠标所指格方框，颜色按 `评估()` 结果 |
| 时间 | `时间/时间tick.cs` | `Update` 累加 → 每 `1/每秒刻数` 秒发一次 `每刻` 事件 |
| 环境 | `时间/环境演化.cs` | 每刻判断该不该衰减/扩散，遍历所有格子加/减属性 |
| 作物 | `作物/作物系统.cs` | 播种 / 收获 / 每刻推进生长 / 生成作物视觉；事件 `播种完成`、`收获完成` |
| 作物数据 | `作物/作物定义.cs`、`作物/作物状态.cs` | ScriptableObject 定义（图标、4 帧、成熟秒数）与运行时状态（已生长秒、阶段） |
| HUD | `玩家HUD.cs` | 每帧按 `当前手持道具` / `正在互动` 刷新高亮、缩放、透明度、播种图标 |
| 调试 | `调试/调试面板.cs` | `F1` 只读面板；整段 `#if UNITY_EDITOR`，打包时不存在 |
| 一次性搭建工具 | `搭建HUD.cs`、`搭建地图系统.cs`、`搭建作物系统.cs`、`TilemapSetup.cs`、`相机跟随.cs` | 编辑器菜单，幂等重建对应内容（见 §7.2） |

**一路数据是怎么流过去的**（以「浇水」为例）：

```
玩家互动.Update  →  左键 → 尝试使用道具()
      → 地图交互.取鼠标所在格() → 在范围/可达 判定
      → 地图交互.对格子使用(坐标, 水壶)
      → 地图数据.加属性(坐标, +20, 0, 0)  → clamp → 地图规则.判定类型()
      → 类型变了 → 类型变化 事件 → 单元格显示.应用() → SetTile 换瓦片
      → 玩家互动.开始动作() → Animator 播「水壶_方向_落」1.4 秒 → 自动结束
```

|---|---|
| `数据/地图/地图规则.asset` | 属性上下限、类型判定阈值、交互范围格数、可达检测窗口、各道具增减量 |
| `数据/地图/单元格类型/{草原,旱地,普通土地,纯水}.asset` | 初始水分/养分/植被、用哪些瓦片、是否可通行、是否参与初始识别、每刻变化（时间系统预留） |
| `数据/作物/环境规则.asset` | 衰减/补水的间隔刻与数值、补水半径 |
| `数据/作物/{小麦,苹果}.asset` | 显示名、图标、4 张成长帧、收获物、成熟秒数 |

另外这两个在场景里改：

- `时间系统 → 时间tick → 每秒刻数`（默认 4，调大 = 快进）、`运行中`（取消勾选 = 暂停时间）
- `玩家 → 玩家移动 → 速度`（默认 5 世界单位/秒；角色约 1 单位高，5 偏快，3 更跟手）

### 7.2 重建资产（编辑器菜单）

菜单栏 **工具**：

| 菜单 | 作用 | 注意 |
|---|---|---|
| `工具/一键准备瓦片地图` | 重切 `瓦片地图/素材` 下所有 PNG、重建 571 个 Tile 与 4 张调色板 | **会重新生成 Tile 资产（guid 变化）**，已用旧 Tile 画好的格子会变空白 —— 只在重建地图时用，先备份场景 |
| `工具/搭建地图系统` | 建 4 个类型资产 + 规则资产 + 光标 prefab + 场景三个组件接线 | 已有资产不会被覆盖 |
| `工具/搭建作物系统` | 拷入并切作物图/草地杂物图、建 35 个杂物瓦片 + `草地杂物` 调色板、建作物定义/环境规则/作物视觉 prefab、建 `时间系统` `作物系统` 并接线 | 幂等，可反复跑 |
| `工具/搭建HUD` | 按当前槽位表重建整个 HUD 层级并接线 | 会删掉旧的 `HUD` 重来，手动改过的 HUD 会被覆盖 |

### 7.3 加内容

**加瓦片 / 新调色板**
1. 把 PNG 放进 `Assets/瓦片地图/素材/`，导入设置照 §5.1（PPU 16 / Point / Uncompressed / Multiple）。
2. 在 `TilemapSetup.cs` 的调色板表里加一项（或照 `搭建作物系统.建调色板()` 的写法新建一张）。
3. 跑对应菜单，然后在 Tile Palette 窗口选调色板、选 Active Tilemap 开画。

**加作物**
1. 准备一张 16×16 网格的成长图（4 帧 + 图标 + 收获物）。
2. 复用 `搭建作物系统.切作物贴图()` 的切片逻辑，生成 `作物定义.asset`（`成熟秒数` 自己定）。
3. 把新定义加进场景里 `作物系统 → 定义表`。
4. 想让它能按 `3` 选中：`作物品种` 枚举加值 + `玩家互动.处理播种按键()` 加一个 `digit3Key`。HUD 图标会自动跟随 `当前定义.图标`。

**加属性 / 加类型**
- 加属性：`地图/单元格属性.cs` 的枚举加一项（`单元格属性表.数量` 会自动跟着变，`数值[]` 定长数组自动扩容）；再到 `地图规则` 里给它加阈值/增量。
- 加类型：`地图/单元格类型.cs` 枚举加一项 + 新建一个 `单元格类型定义.asset` + 加进 `地图数据 → 类型表` + 在 `判定类型()` 里插一条规则（**注意优先级顺序**）。
- 新类型的贴图既可以「多张变体随机挑」，也可以只给 1 张固定瓦片（普通土地就是这么做的）。

### 7.4 工程约定（改之前看一眼）

1. **类名 = 文件名**，中文命名（`玩家移动.cs` 里就是 `class 玩家移动`）。Unity 的 MonoBehaviour 靠文件名匹配，改哪个记得一起改。
2. 编辑器工具整段用 `#if UNITY_EDITOR` 包住，菜单都挂在 **工具** 下。
3. 数值不要硬编码在逻辑里，加个 `[SerializeField]` 字段或丢进 ScriptableObject。
4. 场景里引用的是 **guid**：移动/重命名资产要连 `.meta` 一起移动，否则引用会断。
5. 场景 YAML 里中文字段名是 `\uXXXX` 转义（例如 `"\u52A8\u4F5C\u65F6\u957F"`），用文本工具搜中文是搜不到的。
6. 排序层只有一个硬规矩：地表 < 作物 < 角色 < 光标（见 §3.7）。

### 7.5 常见坑（都踩过）

| 现象 | 原因 / 解法 |
|---|---|
| 瓦片染色不起作用 | Tile 资产带 `TileFlags.LockColor` 时 `Tilemap.SetColor` 会被忽略；本项目统一 `TileFlags.None` |
| 场景里引用突然全变 `fileID: 0` | `AssetDatabase.Refresh()` 之后旧引用会变「假 null」，必须按路径重新 `LoadAssetAtPath` 再写字段 |
| 角色卡在碰撞层上/穿墙 | 瓦片的 `ColliderType` 是 `None` 时 Tilemap Collider 收不到形状；碰撞层用的瓦片要设 `Sprite`，并在改完后 Reset 一下 Tilemap Collider |
| 打包报 `UnityEditor` 找不到 | 运行时脚本里混进了 `using UnityEditor`；用 `#if UNITY_EDITOR` 包住 |
| `Input.GetAxis` 报异常 | 项目只启用新 Input System；用 `Keyboard.current` / `Mouse.current` |
| 中文路径的 `.ps1` 报「找不到源文件」 | PowerShell 5.1 按 ANSI 读脚本；存成 **UTF-8 带 BOM** |
| HUD 上的中文不显示 | Unity 6 内置字体没有中文字形；HUD 只用 ASCII，中文走调试面板的系统字体 |

### 7.6 不改场景的验证手段

- **调试面板（F1）**：时钟刻数 / 实测刻率、衰减·扩散次数、鼠标格的类型与三项属性、是否在 4×4 内、是否可达、作物进度。
- **快进**：把 `时间tick.每秒刻数` 临时改成 40（10 倍速），普通土地约 5 秒退旱地、作物 24 秒成熟；验完改回 4。
- **只看时钟**：Play 中选中 `时间系统`，看 `已过刻数` 每秒跳 4。

## 8. 待办 / 已知限制

- **没有背包**：收获只发事件 + 打日志；`Basic_Plants.png` 最右一列的作物贴图（`收获_小麦` / `收获_苹果`）已切好待用。
